This path has a deliberate mistake: the "No" option names a step called "Restart the router", but the step is called "Restart the modem". Readers see this as a normal article. Authors see a red Path check at the top that names the problem.

Decision: Is the light on the modem green?

  • Yes → Run a speed test
  • No → Restart the router

Action: Run a speed test

Open a speed test site and note the download speed.

End: Speed test done.

Action: Restart the modem

Unplug the modem for 30 seconds, plug it back in, and wait for the light to turn green.
