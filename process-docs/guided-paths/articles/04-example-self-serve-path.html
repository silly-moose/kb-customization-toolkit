Can't open an article someone sent you? Answer a few questions to find out why.

Decision: What do you see when you open the link?

  • A sign-in page → Sign in first
  • A message that the page is restricted → Ask for access
  • A "page not found" message → The article moved or was removed

Action: Sign in first

This knowledge base is private. Sign in with the account your organization gave you, then open the link again.

End: You should see the article now. If not, start again and choose a different answer.

Action: Ask for access

Some articles are only for certain teams. Ask your knowledge base administrator to add you to the reader group that can see it, and send them the link.

End: Your administrator can give you access.

Decision: The article moved or was removed

Search for the article's title.

  • I found it → Found it
  • Search didn't find it → Still need help

Action: Found it

Bookmark the new link so you have it next time.

End: Glad you found it.

Action: Still need help

Contact your knowledge base administrator. Tell them which link you used and what you saw.
